# Atividade: App de Mangás e Animes (estilo Crunchyroll)

Projeto Flutter de exemplo com foco em interface, componentização e navegação.

Como executar:

1. Tenha o Flutter SDK instalado: https://flutter.dev/docs/get-started/install
2. No terminal, na pasta do projeto, rode:

```bash
flutter pub get
flutter run
```

O app abre direto na Tela de Perfil que contém:
- Foto de perfil, nome e bio
- Indicadores: títulos, seguidores, seguindo
- Botão "Editar Perfil" (exemplo)
- Grade com capas dos títulos da lista do usuário

Arquitetura simples: componentes em `lib/widgets`, telas em `lib/screens`, dados em `lib/models`.
